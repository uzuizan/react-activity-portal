# React Activity Portal

A single responsive React application containing five practical activities:

1. Login Authentication
2. Student Grade Evaluation
3. Password Strength Checker
4. Electricity Bill Calculator
5. Employee Attendance Checker

## Run the project

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for production

```bash
npm run build
```
